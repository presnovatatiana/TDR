Benutzung im Browser Google Chrome
----------------------------------
Die Website kann direkt im Browser Google Chrome geöffnet werden.

So funktioniert es:

1. Den Projektordner öffnen.
2. Sicherstellen, dass sich index.html, style.css, script.js und der Ordner assets im gleichen Hauptordner befinden.
3. Die Datei index.html mit Google Chrome öffnen.


- Rechtsklick auf index.html
- "Öffnen mit" auswählen
- Google Chrome auswählen



Empfohlene Testumgebung
-----------------------
Die Website wurde besonders für folgende Ansichten optimiert:

Desktop:
- ab 1280px Breite
- Hauptansicht: 1280 x 832 px

Mobil:
- iPhone 14 Pro Max
- ca. 430 x 932 px

Die Desktop-Ansicht ab 1280px wurde nicht verändert.


Mobile Ansicht in Google Chrome testen
--------------------------------------
Um die mobile Ansicht zu testen:

1. Website in Google Chrome öffnen.
2. Rechtsklick auf die Seite machen.
3. "Untersuchen" auswählen.
4. Oben links im Entwicklerfenster auf das Geräte-Symbol klicken.
5. Als Gerät "iPhone 14 Pro Max" auswählen.
6. Die Seite neu laden.

Falls "iPhone 14 Pro Max" nicht direkt angezeigt wird:
- Oben bei den Geräte-Einstellungen ein eigenes Gerät mit ca. 430px Breite und 932px Höhe einstellen.


Funktionen der Website
----------------------
Die Website enthält folgende Funktionen:

Responsive Navigation
- Auf Desktop wird die Navigation horizontal angezeigt.
- Auf Mobil wird ein Menü-Button angezeigt.
- Beim Klick öffnet sich die mobile Navigation.
- Beim Klick auf einen Menüpunkt schließt sich das Menü automatisch.

Hero-Bereich
- Großes Hintergrundvideo.
- Titel, Beschreibung und Call-to-Action-Buttons.
- Das Video läuft automatisch, ist stummgeschaltet und wiederholt sich.

Tauchspot-Karte
- Interaktive Karte mit fünf markierten Tauchspots.
- Jeder Tauchspot hat ein eigenes Icon.
- Beim Klick auf ein Icon öffnet sich der passende Inhalt im Accordion.
- Die Karte zoomt automatisch zum ausgewählten Tauchspot.
- Auf Desktop kann die Karte zusätzlich mit gedrückter Alt-Taste und Mausrad gezoomt werden.
- Die Karte kann mit gedrückter Maustaste verschoben werden.
- Auf Mobil wird die Karte vollständig sichtbar und untereinander mit dem Panel dargestellt.

Tauchspot-Accordion
- Die Tauchspots sind als Accordion aufgebaut.(Overlay)
- Beim Öffnen eines Tauchspots wird der passende Text und ein Bild angezeigt.
- Beim Zuklappen wird die Karte zurückgesetzt.
- Karte ist Überarbeitet nach Vorgabe

Kursbereich
- Mehrere Kurskarten mit Kurzbeschreibung.
- Über den "mehr"-Button können weitere Details eingeblendet werden.

Buchungsformular
- Das Formular enthält Eingabefelder für Name, E-Mail, Kurs, Termin und Nachricht.
- Die Kursauswahl aktualisiert die Kursinformationen.
- Der Button wird erst aktiv, wenn die notwendigen Angaben korrekt ausgefüllt sind.
- Das Formular ist als Frontend-Demo umgesetzt und versendet keine echte Buchung an einen Server.

Kontaktbereich
- Kontaktinformationen und Kontaktformular.
- Das Formular dient ebenfalls als Frontend-Demo.



Browser-Kompatibilität
----------------------
Getestet und optimiert für:

- Google Chrome
- Desktop ab 1280px
- Mobile Ansicht iPhone 14 Pro Max

Andere moderne Browser wie Safari, Firefox oder Microsoft Edge sollten die Website ebenfalls anzeigen können. Die Hauptoptimierung wurde jedoch für Google Chrome vorgenommen.


Responsive Verhalten
--------------------
Die Website passt sich an verschiedene Bildschirmgrößen an.

Auf Desktop:
- Mehrspaltige Layouts
- Große Bilder
- Horizontale Navigation
- Interaktive Karte mit seitlichem Panel

Auf Mobil:
- Inhalte stehen untereinander
- Navigation wird als aufklappbares Menü angezeigt
- Texte, Bilder und Kartenbereich passen sich an die Bildschirmbreite an
- Die Karte wird vollständig sichtbar dargestellt
- Buttons und Formulare sind besser auf Touch-Bedienung angepasst
